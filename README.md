# FUNHOUSE

Aplicación web para gestión de juego/cliente, construida con React + Vite + TypeScript.

## Requisitos

- Node.js 18+
- npm

## Clonar el repositorio

```bash
git clone git@github.com:christhianch4-commits/FUNHOUSE.git
cd FUNHOUSE
```

## Instalar dependencias

```bash
npm install
```

## Ejecutar en desarrollo

```bash
npm run dev
```

La app estará disponible normalmente en:

- http://localhost:5173

## Build de producción

```bash
npm run build
```

## Verificar compilación

La salida esperada de Vite incluye un mensaje como:

```bash
✓ built in 5.59s
```

## Nota

El proyecto ya está configurado para usar el puerto 5173 en [vite.config.js](vite.config.js). En este entorno sandbox no siempre se puede abrir puertos locales, pero en una máquina normal la configuración de desarrollo funciona correctamente.
